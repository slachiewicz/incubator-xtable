# Bundled dependencies whose license cannot be established from the artifact
# itself. release/scripts/validate_jar_license_layout.sh fails on any
# UNMAPPED-LICENSE in a generated LICENSE that is not listed here, so this file
# is the only way an unresolved license reaches a release - deliberately, and in
# writing.
#
# Do not add an entry to make a build go green. Add one only when the artifact
# genuinely does not say, and record what was checked. Every entry is a question
# for legal-discuss or for the dependency's own project, not a resolution.
#
# Before adding one, check the -sources.jar. Two dependencies that looked
# unresolvable from their POM and binary jar - javolution 5.5.1 and
# javax.servlet.jsp:jsp-api 2.1 - state their license plainly in the file headers
# of the sources jar published alongside them on Maven Central. Both are recorded
# in supplemental-models.xml instead of here.
